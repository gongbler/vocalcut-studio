# 🎙️ VocalCut Studio (데모)

노래·영상을 올리면 **AI 가 보컬과 MR 을 나누고(Demucs), 가사를 받아 적어 자막을 만들고(faster-whisper),
자르기·믹스·한글 자막 입히기**까지 브라우저에서 할 수 있는 편집 스튜디오입니다.

- 체험용 데모: 올린 파일은 **나만 볼 수 있고 약 60분 뒤 자동 삭제**됩니다.
- **본인에게 권리가 있는 파일만** 올려 주세요 (직접 녹음한 노래, 무료 음원 등).
- 무료 CPU 서버라 AI 작업은 몇 분 걸릴 수 있어요. 파일은 5분 이하, AI 작업은 3분 이하.

이 Space 는 저장소의 `Dockerfile` 로 만들어집니다. 설계·측정·문제 해결 기록은 프로젝트 README 를 참고하세요.
